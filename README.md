# Hotel Reservation System

## Description
A Java console-based Hotel Reservation System that allows users to view available rooms, book rooms, cancel reservations, and manage room availability.

## Features
- View Available Rooms
- Book Room
- Cancel Reservation
- Room Categories (Standard, Deluxe, Suite)
- Payment Simulation

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList

## How to Run

```bash
javac Room.java HotelReservationSystem.java
java HotelReservationSystem
```

```
Room.java
HotelReservationSystem.java
```
